# North Bank

Every Arsenal men's article from Arseblog, the Guardian, the Telegraph, The Athletic and BBC Sport, on one home-screen app.

A scheduled GitHub Action collects stories about every 20 minutes and publishes them to GitHub Pages. Saved article text and comments are encrypted with `READER_PASSCODE`, so this public repo and site don't republish publishers' content.

Sources that charge subscribers show a headline and link only.
